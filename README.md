Desenvolvi um sistema em Python "iniciante", chamado FoodRegister, focado no gerenciamento de restaurantes através do terminal (CLI). O projeto foi criado para praticar lógica de programação, estruturas de dados, funções e organização de código. 



 Funcionalidades do Sistema :

Cadastro de novos restaurantes

 Listagem completa de restaurantes cadastrados

 Alteração de status (Ativado/Desativado)

 Interface interativa no terminal

  Navegação por menu

 Tratamento de erros com try/except

 Organização modular utilizando funções



Tecnologias Utilizadas :

Python

Terminal/CLI

Biblioteca "os"

Estruturas de dados (list e dict)

Funções

Condicionais e loops

Tratamento de exceções
